# วางแผนภาษีเงินได้บุคคลธรรมดา ปีภาษี 2569 (2026)

เครื่องมือคำนวณและวางแผนภาษีเงินได้บุคคลธรรมดาของไทย ทำงานทั้งหมดในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์ ไม่มีการส่งข้อมูลออกนอกเครื่อง

## ความสามารถ

- **คำนวณภาษีตามอัตราก้าวหน้า** ครบทั้ง 8 ขั้น พร้อมแสดงว่าเงินได้สุทธิกระจายอยู่ในขั้นใดบ้าง
- **อ่านสเตทเมนต์ธนาคารอัตโนมัติ** — อัปโหลดไฟล์ PDF (รองรับไฟล์ที่ตั้งรหัสผ่าน) ระบบดึงเฉพาะรายการที่โอนเข้าจากบริษัทที่ระบุ แล้วแยกเป็นเงินเดือนกับค่าคอมมิชชั่นให้ แก้ประเภทรายบรรทัดได้เอง
- **ค่าลดหย่อนครบทุกหมวด** รวม RMF, Thai ESG, Thai ESGX, กองทุนสำรองเลี้ยงชีพ, ประกันชีวิตแบบบำนาญ, กอช., ประกันชีวิต/สุขภาพ, ดอกเบี้ยบ้าน, บิดามารดา, บุตร, เงินบริจาค พร้อมตัดเพดานตามกฎหมายอัตโนมัติ
- **เตือนเงินที่จ่ายไปแล้วแต่ใช้สิทธิไม่ได้** เช่น เบี้ยประกันสุขภาพส่วนที่เกิน 25,000 บาท
- **ระบบแนะนำการลดหย่อน** วิเคราะห์จากอัตราภาษีขั้นสูงสุดว่าควรซื้อกองทุนเพิ่มหรือไม่ เท่าไร และคุ้มค่าแค่ไหนเมื่อเทียบกับระยะเวลาที่เงินถูกล็อก
- **วิเคราะห์การลดขั้นภาษี** บอกว่าต้องลดหย่อนเพิ่มเท่าไรจึงจะลงไปขั้นถัดไป และเตือนเมื่อการไล่ลดขั้นไม่คุ้มค่า
- บันทึก/โหลดข้อมูลเป็นไฟล์ JSON, พิมพ์เป็น PDF, โหมดสว่าง/มืด, ใช้งานบนมือถือได้

## วิธีใช้

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเปิดผ่าน GitHub Pages

### เผยแพร่บน GitHub Pages

1. push โฟลเดอร์นี้ขึ้น repository
2. ไปที่ **Settings → Pages** เลือก Source เป็น branch `main` โฟลเดอร์ `/ (root)`
3. เปิด URL ที่ได้

## โครงสร้างไฟล์

```
index.html                  แอปทั้งหมด (HTML + CSS + JS ในไฟล์เดียว)
vendor/pdf.min.js           pdf.js สำหรับอ่านไฟล์ PDF
vendor/pdf.worker.min.js
```

`index.html` จะโหลด pdf.js จากโฟลเดอร์ `vendor/` ก่อน ถ้าไม่พบจะไปโหลดจาก CDN แทน
ดังนั้นถ้าคัดลอกเฉพาะ `index.html` ไปใช้ก็ยังทำงานได้ตราบใดที่ต่ออินเทอร์เน็ต ส่วนการใช้งานแบบออฟไลน์ให้เก็บโฟลเดอร์ `vendor/` ไว้ด้วย

## ความเป็นส่วนตัว

ไฟล์สเตทเมนต์ถูกอ่านด้วย JavaScript ในเบราว์เซอร์เท่านั้น ไม่มีการอัปโหลดไปที่เซิร์ฟเวอร์ใด ๆ และไม่มีการเก็บข้อมูลลง localStorage หรือคุกกี้ ปิดแท็บแล้วข้อมูลหายทันที หากต้องการเก็บไว้ให้กดปุ่ม “บันทึกข้อมูล (.json)”

## หลักเกณฑ์ภาษีที่ใช้ (ปีภาษี 2569)

| รายการ | เพดาน |
|---|---|
| ค่าใช้จ่ายเงินได้ 40(1)(2) | เหมา 50% ไม่เกิน 100,000 |
| ค่าใช้จ่ายเงินได้ 40(5) ค่าเช่าอาคาร | เหมา 30% หรือตามจริง |
| ผู้มีเงินได้ / คู่สมรสไม่มีเงินได้ | 60,000 / 60,000 |
| บิดามารดา | คนละ 30,000 (สูงสุด 4 คน) |
| ประกันสังคม | 9,000 |
| ประกันชีวิต + สุขภาพ | รวม 100,000 (สุขภาพส่วนตัวไม่เกิน 25,000) |
| ประกันสุขภาพบิดามารดา | 15,000 |
| ดอกเบี้ยเงินกู้ที่อยู่อาศัย | 100,000 |
| RMF | 30% ของเงินได้ ไม่เกิน 500,000 |
| ประกันชีวิตแบบบำนาญ | 15% ของเงินได้ ไม่เกิน 200,000 |
| กองทุนสำรองเลี้ยงชีพ | 15% ของค่าจ้าง |
| กอช. | 30,000 |
| **เพดานรวมกลุ่มเกษียณทั้งหมด** | **500,000** |
| Thai ESG | 30% ของเงินได้ ไม่เกิน 300,000 *(วงเงินแยกต่างหาก)* |
| เงินบริจาค | ไม่เกิน 10% ของเงินได้หลังหักค่าใช้จ่ายและลดหย่อนอื่น |

**SSF** สิ้นสุดสิทธิลดหย่อนแล้วตั้งแต่ 1 มกราคม 2568 การซื้อใหม่ในปี 2569 ไม่ได้สิทธิ

## ข้อจำกัดความรับผิด

เครื่องมือนี้เป็นการประมาณการเพื่อการวางแผนเบื้องต้นเท่านั้น **ไม่ใช่คำแนะนำทางภาษี กฎหมาย หรือการลงทุน** หลักเกณฑ์ภาษีเปลี่ยนแปลงได้และแต่ละคนมีเงื่อนไขเฉพาะตัว โปรดตรวจสอบกับกรมสรรพากรหรือผู้เชี่ยวชาญด้านภาษีก่อนตัดสินใจลงทุนหรือยื่นแบบจริง การลงทุนในกองทุนรวมมีความเสี่ยง ผู้ลงทุนควรศึกษาข้อมูลก่อนตัดสินใจ
